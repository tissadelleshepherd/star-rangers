# `story-bible/` — authorial planning, permanently unpublished

Never rendered, and that is policy (settled 2026-07-25): this is the only place spoilers live. The public `/story-engine/` section is derived from it, never a mirror. Story content under CC BY-NC-ND 4.0.

**Start with `open-questions.md`**: every undecided thing in one place, with a pointer to where it was raised. Read it before work that touches an intake, and add a line whenever a direction leaves something undecided.

These are status documents and they go stale; verify against the repo before acting on any of them, and correct the note rather than working around it. Prefer editing an existing note to adding a new one.
