# `prompts/` — the story-engine prompt

`star-rangers-universe-engine.md` is the system prompt for proposing canon-safe expansions to this repository: canon-consistent, single-timeline, append-safe, structured for conversion into front-matter entries. It describes the repo's content model to a model.

Story content under CC BY-NC-ND 4.0, not engine code. It is a working document rather than a page, and the rules it encodes are the ones in `CLAUDE.md`; when the two differ, `CLAUDE.md` is current and this file needs updating.
