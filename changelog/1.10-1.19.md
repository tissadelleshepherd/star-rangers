## [1.19.0] - 2026-08-11

### Fixed

- **The cPanel domains' CSP now permits Pagefind's WebAssembly, so search can actually run there** (2026-08-11). `src/static/.htaccess`'s `script-src 'self' https:` carried neither `'wasm-unsafe-eval'` nor `'unsafe-eval'`, and Pagefind 1.x compiles a WASM module in the browser at `init()` — Chromium-family browsers gate that compilation on `script-src`, so the policy refused it. The failure was invisible by design: `src/js/search.js` deliberately swallows a failed import so the dev server's index-less search box "silently does nothing", and a CSP-blocked production search box looks exactly the same — typing returns nothing, no error, on every domain that serves `.htaccess` (GitHub Pages ignores the file, so search worked there and masked the breakage). `script-src` gains `'wasm-unsafe-eval'` — WASM compilation only, not JS `eval` — and the catch in `search.js` now logs a `console.warn`, so the next production-only failure of this class is at least distinguishable from "no index yet" without reading the deploy scripts.

- **Excluded scene-POV pages no longer leak chapter metadata into search and page heads** (2026-08-11). A scene-POV page of an excluded chapter gated only its *body* on `item.included`: the header above the gate — POV character name, in-universe timestamp and location — rendered unconditionally inside `data-pagefind-body`, and the computed `title`/`description` carried the real chapter title into `<title>`, the meta description and the Open Graph tags. So on every build not opted into `church-space`, that private season's scene-POV pages were searchable (the built index carried "Brother Fintan", "2827 UCSD, late autumn" and "Cnoc na mBeach, the Keeper's lodge and hives") and their heads named "The Night Office". This is the class of leak the 2026-08-03 excluded-placeholder fix declared it had checked for and not found — it existed, in the one page family that opts out of the layout-swap convention, the same blind spot `src/scene-pov.njk`'s `robots` comment already documents; `src/sitemap.njk` had the matching guard and the search path did not. The `<article>` now takes `data-pagefind-ignore` when `item.included` is false (dropping the page from the index entirely, 530 → 527 pages on a default build — the private season's three POV pages), and `title`/`description` gate the same way, mirroring the excluded-page metadata every layout-swapped page gets from `.eleventy.js`. The placeholder page still *renders* its header block to readers of that build; whether it should is a separate judgement left open.

The release where the record wrote down what it had been standing on. At machine law's street level, the certification-status vocabulary the corpus was already using gets registered — **kernel-compliant** and **uncommissioned**, an axis of certification status rather than AI-ness — while the AI Safety Kernel gains Five-O's manufacture remit and an open custody question, and made minds and biological life are filed as sibling formtypes with the safety of made minds an archetype, which is why unrelated cultures keep converging on recognisably similar constraints without contact. At the cosmology's top of the stairs, **[The Archewright](src/lore/archewright.md)** and **[Inside an Archecluster](src/lore/archecluster.md)** give the two load-bearing tier terms their general pages — nothing observes an Archewright, so both are written in the only register the tier permits, convergence read as handwriting — and the Five Layers page settles whether the layers nest: they do not, being concentric in constraint and ragged in registration. The Institute closes the release with its paper on the doctrines of the dead, three claims considered separately and its own best tool recorded as failing. Everything here landed on 2026-08-11, the day after 1.18.0.

- **Every deploy now stamps what it shipped, and every domain can be asked** (2026-08-10). Nothing recorded what any live domain was serving — not the deploy email, not the server, not the site (`assetVersion` is a cache-busting build token, not a release). The version template is excluded from collections, so it reaches no sitemap, search index or listing page. `deploy-lib.sh` stays byte-identical between this repo and `dermot-cochran-photography`; the version reads as a bare short commit there, that repo carrying no tags.

- **Cron-driven pull-and-deploy for the cPanel clones** (2026-08-10). Nothing connected a merge to a live domain: cPanel does not poll GitHub and GitHub cannot push into cPanel, so a merge to the deploy branch updated every clone's *remote* and none of their *checkouts* — the merge real, CI green, and every production domain still serving the previous build until someone opened cPanel and clicked **Update from Remote**. New `scripts/cpanel-autopull.sh` is a cron entry point that fast-forwards the checkout and hands off to `scripts/cpanel-deploy.sh`, but **only when that moves the commit the clone has successfully deployed** — tracked in `$HOME/.cpanel-autopull/` rather than by comparing HEAD before and after the pull, because a pull that succeeds followed by a deploy that fails leaves HEAD already advanced, so a before/after test would see "nothing new" on the next run and never retry, leaving the site stale behind a cron job that looks healthy. Silent when idle (cron mails any output, and a ten-minute job must not mail every run); `--force` for after a `deploy.conf` edit, which is untracked and so never moves HEAD but does change what gets built; `--status` to inspect without acting; `--verbose` to narrate. Locks with `mkdir` (`flock` is not guaranteed on cPanel hosts) so two runs cannot rsync one document root at once, reclaiming a lock whose owning process is gone. Pulls `--ff-only` on the principle that a deployment checkout is never a place work is done, so anything that cannot fast-forward is a fault to report rather than a merge to resolve. Adds no logging on top of the deploy's own — `deploy-lib.sh` already mails and persists that — keeping only a small pull/skip/deploy decision log so "why did the site not update" is answerable without a mailbox. Shared **byte-identical** with the `dermot-cochran-photography` copy, same convention as `deploy-lib.sh` and `ensure-node.sh`, and added to the CI shellcheck list in both repos. README gains an "Automatic deployment from cron" section with the install line, the per-flag behaviour, exit codes, and a verify-before-you-trust-it step. Recorded there too: **forking would not have solved this** — a GitHub fork does not auto-sync from upstream either, and a cPanel clone pulls from whatever URL it was given without subscribing to anything at either end.

### Fixed

- **Character portraits are 16:9, and `scripts/generate-themes.js` could not run on Windows** (2026-08-10). Two independent faults, both surfaced while reading a story-bible note that was about to be retired. **The portrait ratio:** `.character-portrait` is `aspect-ratio: 16 / 9` with `object-fit: cover`, so a taller frame delivered into it is cropped to a horizontal band and most of the image is discarded. The conventions table never stated orientation at all, which is how it stayed missable — and the first full generation run put all twelve character portraits out at 3:4 before anyone checked the CSS. A manifest row now counts as generated **only if it was produced at the aspect currently in force**, so anything made under a different one is stale by definition and drops back to pending for the next run to redo, rather than needing someone to work out which files to delete; `src/css/main.css` gains a comment at the rule recording that the corpus is generated to match it, so a future change to the ratio is understood to change the images rather than the reverse. **The theme generator:** its regexes are written against `\n`, and with no `.gitattributes` a checkout under `core.autocrlf=true` hands it CRLF — so every pattern silently failed to match and it reported a rule "not found in `main.css`" that was plainly present. It was therefore unrunnable on the machine where `main.css` is edited, which is exactly the drift it exists to prevent; line endings are now normalised on read, fixing every pattern at once. The themes turn out not to have drifted — regenerating all eight changes nothing but the new comment.

This is the *fourth* time it has drifted: it sat at `1.5.0` through the 1.6.0 and 1.7.0 releases, which is why the release checklist called it out in bold as "the step that gets missed" — and it was then missed three more times with that warning in place. **A checklist item missed four times is not a discipline problem**, so it has stopped being a checklist item.
  - **[`scripts/sync-version.js`](scripts/sync-version.js)** writes the line from `package.json` (`node scripts/sync-version.js`) or verifies it (`--check`). Two hooks make it unmissable from either direction: a **`version` lifecycle script** in `package.json` means `npm version X.Y.Z --no-git-tag-version` — already step 1 of the checklist — updates the README as a side effect; and **`npm test` runs `--check`**, so a version edited by hand, bypassing `npm version` entirely, fails CI instead of shipping stale. Release checklist drops from four steps to three.
  - **It fails loudly when its anchor disappears.** If the README is restructured so no `Current version: **X.Y.Z**` line matches, the script exits non-zero in *both* modes rather than passing on a line it cannot find — a check that silently succeeds once its anchor moves is worse than no check, because the failure is invisible. The error says to retire the script and its two hooks together, or restore the line.
  - **Deliberately not a `VERSION.md`.** Considered and rejected: nothing in the repo reads a version file, and nothing reads `package.json`'s version programmatically, so a dedicated file would be a *third* copy of a number that already lives in `package.json` and `CHANGELOG.md`. GitHub markdown cannot include one file in another either, so the README would still have to restate it. The fix for a value duplicated by hand is to stop duplicating it by hand, not to add another place for it to drift.
  - `npm test` is **three checks** now, not two; `CLAUDE.md`'s Commands section and its "no separate unit-test framework" paragraph both updated to say so.

### Added

- **Lore: what Layer 2 records, Layer 1 does not found** (2026-08-02, #270). ### Added

- **The [Ollune](src/lore/ollune.md) and their world [Cirrane](src/lore/planets/cirrane.md)** (2026-08-01) — a Federation species evolved in a gas giant's upper atmosphere, with a matching [glossary entry](src/glossary/ollune.md). Written to the roster's existing rule that a species' politics falls out of its physiology, and every trait here descends from one constraint: in a hydrogen atmosphere there is no lighter gas to float on, so an Ollune floats on a *warmer* one and pays for its own lift metabolically, hourly, for life. Hence sleep is communal (an unconscious Ollune sinks, and is carried), possession is a permanent metabolic charge rather than an asset, and a people whose word for themselves means *the held* treats trust as a load being borne by named individuals rather than a sentiment. Cirrane has no free oxygen, so **nothing on it has ever burned** — no fire, no smelting, no metal, no launch vehicle, and no route by which the Ollune could have presented themselves to anyone. **The two-channel split is the load-bearing idea.** Pressure sound (**the far word**) is fast, public, unblockable and gone the moment it is uttered; chemical marking (**the near word**) is slow, close-range, attributable to a body and durable. Ollune law gives them opposite jobs — the far word binds nothing, so there are no oaths and no verbal contracts, while the near word binds everything. The consequence is that **raising an alarm is free**: warning and committing are separate organs, not two uses of one, so no Ollune has ever stayed quiet because speaking up would mean owning the problem. Correspondingly a *false near word* is their gravest offence while lying aloud is unremarkable, which is the inverse of the human arrangement and has cost individual Ollune badly in commercial dealings. Two hooks into existing canon, both chosen to avoid ground already held by other species: their zonal bands make **proximity and access different things** — a shoal a thousand kilometres away in the same band is unreachable forever, one three kilometres up is a regular partner — which is the first principle of fold transit, worked out from weather rather than from corridors, leaving the Prismeri their astrogation; and their contribution to the Ranger compact is neither material nor expertise but **procedure**, the discipline of drafting agreements that hold between parties who cannot confer, which is the Federation's own structural problem under no-FTL-communication. The [Safety Corps](src/lore/star-rangers-safety-corps.md) separation of a free, unattributed reported concern from a signed, permanent finding is noted as the same principle the Corps argued its way to over centuries and the Ollune have as anatomy. Cirrane is also the clearest test of the Federation's founding sentence, since it is the one member world whose people could not have proved themselves to anybody, and its delegate is generally not in the room.

  **Volumetric cognition, and why the obvious version of it is the boring one.** The expected reading — surface species think in two dimensions, atmosphere species in three — is stated and then set aside, because what actually distinguishes the Ollune is that they have no privileged *plane* and a ferociously privileged *axis*. A surface species' vertical is the cheap direction with nothing at either end; the Ollune vertical carries every resource, every neighbour, every hazard and **both** available ways to die, while their horizontal is free, infinite and socially empty. Hence no maps — a map projects onto the plane where nothing happens — and a position notation of **depth, bearing and phase** in which the time term is not optional, because on a world where every reference body moves at a different speed a position without a time does not underspecify a location, it fails to denote one. There is no Ollune expression for a place that does not include when you will be at it.

  **Trade runs on carriage, not goods.** A hull crosses in an hour what a shoal waits a generation for, so any visiting trader has a connectivity no native possesses, and the valuable cargo is carriage of the near word — constituting agreements between shoals that could not otherwise exist. That makes the Rangers' charter role as the courier both sides trust the load-bearing member of Cirrane's economy rather than a piece of institutional design. The physics cuts one way only: a near word is attributable to the body that made it, so a carrier cannot forge one, and readable by anyone in proximity, so a carrier can read everything they carry. **Integrity is guaranteed and privacy is impossible** — hence the Ollune have no concept of a confidential agreement and read a non-disclosure clause as a description of an agreement that is not there. And since anything imported must be lifted permanently by whoever accepts it, **the only imports worth having on Cirrane are weightless**: a merchant who understands the place arrives empty and leaves full.

  **Freyari** (2026-08-01) is the Ollune name for the temperate shell — the habitable band itself, not the body it wraps. *Cirrane* remains the Federation survey catalogue name for the whole planet, and the two deliberately do not denote the same object: Cirrane is tens of thousands of kilometres deep, all but a sliver of it irrelevant to everything alive, and Freyari is the sliver. In ordinary usage it doubles as the Ollune word for *everywhere*.

  **Relationship with the [Krenyi](src/lore/krenyi.md)** (2026-08-01). The pairing xenosociology expected to fail — Krenyi do not use social deception, Ollune hold that a falsehood in the far word is unremarkable — and it does not fail, because the Krenyi were already asking for what Ollune anatomy supplies: a species that moves directly to material terms meets one with a dedicated channel for them. The Krenyi are also close to the only species that can accept the far word's standing without hearing a moral defect in it, since *architecture, not virtue* is exactly how the Krenyi describe their own bounded emotional range. **The one serious hazard belongs to the Krenyi**: a far word contradicting a near word is pattern drift by the Krenyi definition, and the Krenyi answer to pattern drift is quiet withdrawal — aimed at someone who has broken no law of their own, who will not be told, and who can only be reached at a passing. The failure mode is not an argument but a Krenyi going silent, correctly by their own lights, over nothing; the fix is the practice they already use against mythification. On fear the two are opposite answers to one question — Krenyi have no deep-fear response to cascade, Ollune have alarms that cost the raiser nothing — and neither quite believes the other's method works. Also pays off a running risk in the entry: the Ollune are tired of being told their body is somebody else's moral achievement, and the Krenyi are constitutionally incapable of telling them so.

The retitle release, and the one that pinned down the top of the Cascade.

The work is now ***Drithane***. This extends the ladder the Conceptual layer already follows by one rung: *Conseleme fixes what any mathematics must satisfy and a Metawright settles which there is; Conseleme fixes that seating must obtain and a Formwright settles which manifold there is.* An earlier draft placed the manifold in the Upper Structure and was wrong — a manifold is a mathematical object, mathematics is settled one tier down, so "it is shared, therefore it is above the realms" begs the question.

A formtype does not say what happens or even what may happen; it settles what shape a thing that happens is permitted to have. ## [1.10.0] - 2026-07-29

The naming release. Every substantive change in it is about a name rather than a fact: a Cascade tier renamed, a Ranger rank restyled, a second rank finally recorded under its full style, one charter clause rewritten so its rank floor cannot be misread, and a journal entry about the single tell the whole set had in common.

**That tell is the release's actual content**, so it belongs at the top. Each entry touched here carried a paragraph whose only job was explaining what its own name did *not* mean. `Dynarch` named a tier after the forces it is least able to alter — the rule-sets are the Worldwright's — and the entry spent a section on the gap. `Starwarden First Officer` named a rank after a relationship it does not have, and its own bullet admitted so in its opening clause. In both cases the explanation was *good*, which is exactly why it survived for months. A well-argued defence of a bad name is a decent piece of writing and a permanent tax on every reader who arrives after it.

**The two renames needed opposite machinery, which is this release's one genuinely load-bearing distinction.** `Dynarch → Mediarch` is the Archive correcting its own vocabulary: no in-universe register ever used the word, so once retired it names nothing, migrates on sight, and takes no dating rule. `Starwarden First Officer → Archwarden` is an institution renaming its own rank in **2833 UCSD**, so both styles are correct for their own periods and pre-2833 records are read as written rather than corrected. The consequence worth having in the record: **not one word of canon prose was altered anywhere in this release.** The two migration rows now sit next to each other in the canonical glossary making opposite claims about the past, and each points at the other so neither can be applied with the wrong rule.

**`MINOR`, and this is the first release where that classification needed an argument.** Earlier entries could justify it with "nothing was removed, renamed or moved" — this one renames two things and moves a page's URL, which reads like that criterion failing. It isn't. `MAJOR` in this project has always concerned the **engine's compatibility surface** — `deploy.conf` keys, themes, build outputs, defaults — and none of those changed. The single moved URL keeps a redirect stub at its old address, and the retired `dynarch` tag is deliberately retained on the renamed entry so any clone narrowing by that topic keeps matching it. Nothing 404s and no configuration breaks, which is the substance the older phrasing was reaching for.

**Tagging.** `v1.10.0` is cut at this release's own merge commit, which does not exist until the release merges — so the tag is always the last step and always separate from this file. ### Changed

- **The rank above Deputy and below Senior is recorded as `Field Officer`** (settled 2026-07-29) — the ladder entry previously gave only the short form **Officer** and described the rank without naming it in full. Same rung, same duties, no reordering: full field-qualified rank, the first tier that can act and be posted independently.
  - **Three live forms, and the reason they coexist is worth the paragraph.** Formal style **Field Officer**; short form **Officer**; colloquially just **Star Ranger** or **Star Ranger officer**. Unlike the three Archwarden styles retired above, none of these is deprecated — the entry keeps all three and explains which register each belongs to.
  - **The colloquial form is genuinely ambiguous, and the entry now says so rather than smoothing it.** "A Star Ranger" names *this rung specifically* and *everyone from this rung upward* — a Line Captain is a Star Ranger and so is the newest Field Officer aboard her vessel. Filed not as a defect but as what happens when a rank is the **threshold of belonging** rather than a step inside it: the rung at which a Ranger stops being supervised and starts being one of the people the word is for. The previous wording called *Star Ranger* a collective term "rather than a rung of its own," which is half the truth — it is both.
  - `Deputy` gains its full style **Deputy Officer** and `Senior` its alternate **Senior Star Ranger**, from the same pass. Recorded in [`star-rangers-command-hierarchy.md`](src/lore/star-rangers-command-hierarchy.md), with `field-officer` added to the page's tags.
- **The Field Triumvirate clause gains a fallback composition** (settled 2026-07-29). The clause previously specified exactly one body — the ranking Line Captain, the nearest vessel's Archwarden, and the next most senior Starwarden reachable — and said nothing about what happens when that cannot be assembled, which left the charter's emergency provision silently unavailable in the circumstances most likely to need it. It now has **two forms in strict order of preference**: the named composition where it can be reached, and failing that **the three most senior officers available, none below the rank of Officer**.
  - **The floor is `Field Officer`, and it is the only rank test the clause makes.** Field Officer is the ladder's full field-qualified rank and the first tier that can be posted and act independently; below it — Deputy Officer, Cadet, Novice — a Ranger works under another officer's supervision by definition, and a body of supervised officers authorising emergency action would be a contradiction, since the supervision is the thing being bypassed. The floor is therefore structural rather than a seniority ornament: it is the line between *can act on their own judgement* and *cannot*.
  - **The clause uses the full style deliberately, and this is load-bearing.** "The three most senior officers available" uses the ordinary word; *none below Officer* would collide with it, and *none below Star Ranger* would collide with the collective term for everyone from that rung upward — which would read as no floor at all. **Field Officer** is the only form of the name that cannot be misread in either direction. Same lesson the Archwarden restyling records, applied to a clause before it cost anything rather than after.
  - **Fallback, not alternative** — an officer cannot prefer it for being quicker to assemble or likelier to produce an agreeable third voice; where the named composition is reachable in the time available it is the only lawful one. **`Available` carries the third condition's own clock:** reachable in time to take part in the decision actually being made, so an officer who could join in an hour is not available to a decision that has minutes. And **seniority decides with no discretion** — the three most senior, in order — because a rule permitting selection permits a convening officer to assemble a body that will agree with them.
  - **What the fallback gives up is stated in the entry rather than concealed.** The named composition is independent by construction: a Line Captain, another vessel's Archwarden and a Starwarden on relay are three different commands, none owing its posting to the others. The fallback has no such property and on one hull can be a captain and two of their own crew. That weakening is accepted because the alternative is a body that cannot convene while people are dying — and the safeguards were never compositional: they are the three conditions, each standing on its own, plus the reporting and review that follow every convening.
  - **Below three eligible officers there is no Field Triumvirate**, and the clause manufactures nothing out of two. What one officer may do at the scene stays with the existing [decision doctrine](src/lore/star-rangers-decision-and-communication.md) — authority sitting with whoever is closest and holds the relevant rank — answered for personally, and never recorded as a Triumvirate.
  - **Nothing retroactive.** The 2831 Dock Seven convening reached the named composition in full and is now noted as the standing example of it; the fallback has never yet appeared on a record anyone has had to review. Recorded in [`star-rangers-command-hierarchy.md`](src/lore/star-rangers-command-hierarchy.md).
- **The force-governance tier is renamed `Dynarch` → `Mediarch`** (settled 2026-07-29) — a pure rename, with **no change of meaning, rank, property or constraint**. Every statement the corpus filed about a Dynarch stands unaltered about a Mediarch, which is why this is filed as Changed rather than as a settlement: nothing was decided about the tier here except what to call it.
  - **The old name pointed at the wrong thing, and the corpus already said so.** *Dynarch* (from *dynamis*, force) named the tier after its subject matter — and the tier's first listed constraint, unchanged since it was written, is that it governs the *operation* of a force and not its design: the rule-sets are the Worldwright's, and no Mediarch can rewrite a zone's physics. The name emphasised the one thing the office is least able to alter.
  - **The new name records what the 2026-07-26 settlement established.** *Mediarch* (from *medius*, the middle) names the mediating office — the Telearch line reaching inside a universe by proxy, standing between a continuity branch native to nowhere and the inside of the thing that branch has to reach. "A Mediarch is a proxy Telearch" now reads as an unpacking of the name rather than as a fact arriving from elsewhere.
  - **`Exarch` is untouched and still co-canonical.** The older devotional and provincial form was already naming the same mediation — a delegated governor holding a province from a distant throne — so the rename brings the formal name into line with the devotional one rather than displacing it. **No in-universe register keeps `Dynarch`**, which is why there is no quoted-as-written exception of the kind the Solar System Concord row carries: devotional sources say *Exarch*, and [The Reading Before a First Vigil](src/codex/the-reading-before-a-first-vigil.md) needed no change beyond its archive note.
  - **Recorded as terminology law**, per the standing rule that a cosmological rename means the canonical-terms list *and* a migration row *and* a corpus sweep: the [canonical glossary](src/lore/glossary/canonical-glossary-and-migration-guide.md) gains a `Dynarch → Mediarch` migration row and a `The name` block, and its "higher celestials" row now notes that the term has been migrated **twice** — `higher celestials` → `Dynarch` → `Mediarch` — so a legacy reading lands on the current name rather than on the intermediate one.
  - **Swept across the corpus in one pass**, hierarchy spines included: [`glossary/mediarch.md`](src/glossary/mediarch.md) (renamed from `dynarch.md`), `telearch.md`, `celestials.md`, `concordant-principal.md`, `high-celestials.md`, `glossary/cosmic-cascade.md`, `lore/cosmic-cascade.md`, `who-governs-a-universe.md`, `physics-comparison.md`, `concordant-membranes.md`, the codex archive note, and `story-bible/canon-consistency-audit-2026-07.md`. Where a page explains the tier's naming history rather than merely using the name — `lore/cosmic-cascade.md` and `who-governs-a-universe.md` — it now records all three names and why each was replaced, so the rename is legible from the record instead of only from this file.
  - **The old URL does not 404.** `/glossary/dynarch/` becomes a redirect stub ([`glossary/dynarch.njk`](src/glossary/dynarch.njk)) pointing at `/glossary/mediarch/`, on the same pattern as `lore/solar-system-concordant.njk`: canonical link, `noindex, follow`, meta refresh, and a sentence saying what moved and why. **`dynarch` is also kept as a tag** on the renamed entry alongside `mediarch`, so any cPanel clone whose untracked `deploy.conf` narrows by that topic keeps matching the page.
  - Verified with `npm test`, `check-internal-links.js` (1832 links, all resolve) and `check-related-terms.js` (204 terms, all resolve) — the last of which is the check that matters here, since `related:` resolves by page **title** and a stale term would have silently degraded to `/glossary/` rather than failing.
- **The rank above Starwarden and below Line Captain is restyled `Starwarden First Officer` → `Archwarden`** (settled 2026-07-29; **2833 UCSD** in-universe). A vessel's second-in-command, one rung above Starwarden and one below Line Captain — **seniority, duties and ladder position all unchanged**. Only the words on the tab moved.
  - **The old style was the most misread title on the ladder, and its own entry said so** in its opening clause. *First Officer* named the post — first officer **of a vessel** — and never meant first officer *to* a Starwarden, but that is how it read to anyone meeting it cold, and the two ranks are consecutive rungs rather than a commander and a deputy. The entry answered this with a paragraph of explanation, which is a tax on every reader rather than a fix. **Archwarden** says senior warden and needs no paragraph. Three written forms are also retired with it — `Starwarden First Officer`, `Starwarden First Class` and `Executive Starwarden First Class` — since one rank carrying three styles was half the problem.
  - **Where the old style actually cost something: the Field Triumvirate clause.** It names a warden-rank and a Starwarden in one breath, so the previous wording read as *the Starwarden First Officer … and the next most senior Starwarden* — implying a chain of command between the two that does not exist, in the one clause where three officers have to know who is who under pressure. Recorded as the reason the Provost track's standing objection was actioned. The 2833 restyling amended that clause and every other regulation naming the rank; **the composition itself did not change.**
  - **No canon prose was altered, by design.** This is an *institution renaming its own rank on a date*, not the Archive correcting its own vocabulary — so both styles are correct, each for its period, and the restyling is dated **after every published chapter**. [`s05e02c03`](src/seasons/s05/e02/s05e02c03.md) is right as published: Shepherd's 2831 Field Triumvirate and the officer who leaves on the last shuttle both keep the older style, quoted as written. Same treatment the 2723 charter preamble gets under the Solar System Concord row.
  - **The two renames in this release need opposite machinery, and the migration map now says so explicitly.** `Dynarch → Mediarch` has **no** dating rule — no in-universe register ever used the word, so once retired it names nothing and migrates on sight. `Starwarden First Officer → Archwarden` **has** one, because the old style was correct until 2833. The rows sit next to each other in the [canonical glossary](src/lore/glossary/canonical-glossary-and-migration-guide.md) making opposite claims about the past, which is correct; each row points at the other so neither is applied with the wrong rule.
  - Recorded in [`star-rangers-command-hierarchy.md`](src/lore/star-rangers-command-hierarchy.md) (ladder bullet, restyling note, Field Triumvirate clause and wording note) and the canonical glossary (new `Archwarden` term entry with its dating rule, plus a migration row). Character pages carry the `Canonical Term (formerly Legacy Term)` first-mention form per the guide's own deprecation policy: [`tissadelle-shepherd.md`](src/characters/tissadelle-shepherd.md)'s Season 4 progression and [`karla-wender.md`](src/characters/karla-wender.md)'s open progression both name the rank currently while flagging the style she held it under. `archwarden` is added to the hierarchy page's tags alongside the retained `starwarden-first-officer`.
